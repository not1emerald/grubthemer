# grubthemer
the official version of grubthemer that allows you to use a gui to set specific settings or  install a theme

install zenity using
fedora/fedora based:
sudo dnf install zenity
Covers: Fedora, RHEL, CentOS, Rocky Linux, AlmaLinux

ubuntu/debian based:
sudo apt install zenity
Covers: Ubuntu, Debian, Linux Mint, Pop!_OS, Elementary, Zorin

arch linux:
sudo pacman -S zenity
Covers: Arch, Manjaro, EndeavourOS

openSUSE:
sudo zypper install zenity

how to launch?:
run this one time: chmod +x /path/to/grubthemer
then this every time you want to launch it: sudo -E ./grubthemer.sh
